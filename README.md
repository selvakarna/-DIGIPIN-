# 🛰️ BhoomiAI — DIGIPIN Satellite AI Change Detection & Bhashini Voice System
### பூமி AI — டிஜிபின் செயற்கைக்கோள் & பாஷினி முறைமை

## Features / சிறப்பம்சங்கள்:
1. **National DIGIPIN Geocoder (4m × 4m Grid)**: Converts India Post DIGIPIN to bounding box coordinates.
2. **Interactive Bitemporal Split Drag Slider**: Compare historical (T1: Jan 2026) vs. current (T2: Aug 2026) satellite imagery.
3. **AI Change Detection Models**:
   - 🟦 New Construction & Building Footprints (+450 m²)
   - 🟥 Deforestation & Green Cover Delta (-18.4% ΔNDVI)
   - 🌊 Water Body Surface Monitoring (ΔNDWI)
4. **MeitY Bhashini Multilingual AI Explanation**:
   - Translations into 22 Indian Languages (தமிழ், हिन्दी, తెలుగు, ಕನ್ನಡ, English).
   - 🔊 Real-Time Voice Text-to-Speech (TTS) reading the report aloud in native Indian accents.
